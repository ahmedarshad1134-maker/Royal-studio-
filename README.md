# Royal Studio - Fine-Art Photography & Cinematography App

A luxury visual production business web application rewritten in React, TypeScript, Vite, and Tailwind CSS.

## Features Preserved & Ported

1. **Home & Public Showcase**:
   - Hero spotlight featuring Royal Studio cinematography, luxury typography, and key trust markers.
   - Client Portal Quick Entry Banner for seamless access to client deliverables.
   - Signature visual services showcase with pricing, highlights, and direct booking actions.
   - Curated portfolio preview with category tabs.
   - "The Royal Standard" value propositions and verified client reviews.

2. **Portfolio Gallery**:
   - Filter by categories: All, Wedding, Engagement, Pre-Wedding, Birthday, Baby/Family, Anniversary, Other Events.
   - High-definition media preview modal with lightbox zoom.

3. **Services & Packages**:
   - 7 Core Studio Services with detailed feature breakdowns, starting rates, and suitable event tags.
   - 4 Signature Packages (Basic Essentials, Standard Classic, Premium Royal, Custom Bespoke) with coverage hours, crew sizes, album specifications, delivery timelines, and optional add-ons.
   - Detailed dedicated views for both Services and Packages.

4. **Multi-Step Booking Wizard**:
   - 5-step guided booking flow:
     - Event Type selection
     - Real-time date availability checking against studio blocked dates
     - Venue / Destination details
     - Package or A La Carte service selection
     - Customer contact details & special notes
   - Confirmation screen with unique Reference ID generation (`ROYAL-2026-XXXX`) and direct WhatsApp Concierge connect.

5. **Customer Area & Private Deliverables Gallery**:
   - Client sign-in / registration with instant demo access.
   - Booking overview with color-coded status badges: *Enquiry Received, Contacted, Quotation Issued, Confirmed, Completed, Cancelled*.
   - Invoice & billing card with line items, total, paid amount, balance due, and printable invoice viewer.
   - Private media deliverables gallery with 4K asset downloads and lightbox viewer.
   - Updates timeline with audit logs.

6. **Reviews & Testimonials**:
   - Verified reviews display with average rating summary.
   - Featured love story spotlight.
   - "Write a Review" interactive form with moderation queue.

7. **About & Heritage**:
   - Studio origins, artistic philosophy, milestones timeline, and lead artists.

8. **Contact & Concierge**:
   - Direct WhatsApp integration, phone, email, studio address, consultation hours, and message form.

9. **Administrator Management Portal**:
   - Restricted admin authentication.
   - Executive dashboard with business metrics (New enquiries, upcoming events, confirmed bookings, pending reviews).
   - Bookings CRM: status transitions, admin notes, audit trail history.
   - Invoices & Billing: search, payment recording (Bank transfer, cash, card, UPI, cheque) with receipt generation, and printable invoice generator.
   - Portfolio Manager: add media, toggle featured/enabled, category assignments.
   - Services & Packages Editor: customize offerings, pricing, and visibility.
   - Review Moderation Queue: approve, feature, or delete submitted reviews.
   - Blocked Dates Manager: block specific dates with custom reasons.
   - Studio Settings: update contact info, social links, hours, and about narrative.

## Tech Stack
- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Cormorant Garamond & Montserrat fonts
- **Icons**: Lucide React
